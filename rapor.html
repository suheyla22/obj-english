Nesne Tanıma Tabanlı İngilizce Kelime Öğrenme Uygulaması
Öğrenci: Süheyla ÖZDEMİR
Numara: 51349548302
Yıl: 2026

1. Proje Tanımı ve Amacı

ObjEnglish, mobil kamera ile çevredeki nesneleri fotoğraflayan ve nesnenin İngilizce adını, Türkçe anlamını, telaffuzunu ve örnek cümlesini kullanıcıya gösteren bir İngilizce kelime öğrenme uygulamasıdır.

Projenin amacı, soyut kelime listeleri yerine kullanıcının günlük hayatta karşılaştığı somut nesneler üzerinden dil öğrenimini desteklemektir. Fotoğraflanan her nesne hem kelime kartı hem de quiz materyaline dönüştürülmektedir.

2. Teknoloji Seçimi

Başlangıçta Flutter + TensorFlow Lite (MobileNet) planlanmıştı. Ancak bu yaklaşımda ciddi kısıtlar ortaya çıktı:

  • MobileNet yalnızca 80 önceden tanımlı nesneyi tanıyabiliyordu
  • Doğruluk oranı %40–60 düzeyinde kalıyordu
  • iOS cihazda test için Mac bilgisayar gerekliydi
  • Hermes motoru ile TF.js uyumsuzluğu yaşandı

Bu sorunlar üzerine React Native (Expo SDK 54) + Google Gemini 2.5 Flash Vision API kombinasyonuna geçildi. Sonuç karşılaştırması:

3. Kullanılan Teknolojiler

  • React Native 0.81.5 / Expo SDK 54 — Mobil uygulama çerçevesi
  • Google Gemini 2.5 Flash API — Görüntü tabanlı nesne tanıma ve dil işleme
  • expo-image-picker / expo-image-manipulator — Kamera erişimi ve görüntü sıkıştırma
  • expo-speech — Sesli telaffuz (Text-to-Speech)
  • AsyncStorage — Yerel veri saklama (geçmiş, XP, seri)
  • React Navigation — 4 sekme navigasyonu
  • expo-haptics / expo-linear-gradient — Dokunsal geri bildirim ve arayüz

4. Uygulama Özellikleri

4.1 Nesne Tarama

Kullanıcı kamera veya galeriden fotoğraf seçer. Görüntü 512px'e küçültülüp Base64'e çevrilerek Gemini API'ye gönderilir. API tek çağrıda şunları döndürür: İngilizce ad, güven skoru, Türkçe anlam, IPA fonetik, örnek cümle, emoji. Sonuç animasyonlu kart olarak gösterilir; hoparlör butonuyla sesli okunur.

4.2 Quiz Sistemi — 3 Mod

  • Flashcard: Fotoğraf gösterilir, kart çevrilince kelime + fonetik + Türkçe anlam açılır
  • Çoktan Seçmeli: Fotoğraf + 4 seçenek; doğru yeşil, yanlış kırmızı, 0.9s sonra geçiş
  • Yazım: Fotoğraf + fonetik ipucu gösterilir, kullanıcı kelimeyi yazar

Her doğru cevap +20 XP, her tarama +10 XP kazandırır. Quiz sonunda kazanılan XP rozeti gösterilir.

4.3 İlerleme Takibi

  • XP tabanlı 10 seviye sistemi (Başlangıç → Efsane)
  • Günlük kullanım serisi (streak) ve en uzun seri kaydı
  • Kelime başına 5 yıldızlı ustalık seviyesi
  • Toplam tarama, doğru/yanlış sayısı ve başarı yüzdesi

4.4 Diğer Özellikler

  • İlk açılışta 3 slaytlı onboarding ekranı
  • Tarama geçmişi (bireysel veya toplu silme)
  • API hata yönetimi: rate limit retry, 4 model fallback, kısmi JSON kurtarma
  • Ortam değişkeni ile API key güvenliği (.env)

6. Sonuç

ObjEnglish, planlanan 13 haftalık geliştirme takviminin 12. haftasında tamamlanmıştır. Orijinal plandan farklı olarak offline TFLite yerine Gemini 2.5 Flash API tercih edilmiş; bu değişiklik tanınabilir nesne sayısını sınırsıza taşımış ve doğruluk oranını önemli ölçüde artırmıştır. Temel nesne tanıma ve sesli telaffuz özelliklerinin ötesine geçilerek quiz sistemi, gamification ve ilerleme takibi de uygulamaya eklenmiştir.

Gelecek Geliştirmeler

  • Gerçek zamanlı (canlı kamera) nesne tanıma
  • Spaced repetition algoritması
  • Backend proxy ile API güvenliği
